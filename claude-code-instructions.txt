## Tech stack
- Astro, static output, deployed with GitHub Pages via GitHub Actions.
- Custom domain hungrykaty.com (public/CNAME), www -> apex.
- Recipes as Markdown in an Astro content collection, one file per recipe, with structured
  frontmatter: title, date, categories, servings, times, hero image, ingredients (list with
  quantities), steps (ordered list), story/intro (body), and a `game` config block.
- Add schema.org Recipe JSON-LD to each recipe page.
- Optimize images (responsive sizes, webp/avif).
- No redirects from old WordPress URLs needed. Make a cute, helpful 404 page that shows
  a recipe grid.

## Visual design
- Light beige gingham background (CSS-generated, not an image).
- Cute, friendly, sticker-sheet style: rounded cards with white outline + soft shadow,
  category buttons as illustrated sticker badges, "Play the recipe" badge on cards.
- Palette inspired by flat cartoon breakfast illustrations: sage green, butter yellow,
  strawberry red, blueberry purple, caramel brown, cream.
- Fonts: rounded/bubbly display font for headings + logo (e.g., Fredoka or Baloo 2), very
  readable soft body font (e.g., Nunito). Recipe text must stay easy to read.
- All illustrations must be ORIGINAL (my inspo images are a stock-style illustration and
  another shop's sticker sheet; use them only as mood reference, never copy them).
- Logo + favicon: an original cute stack of pancakes (butter pat, syrup drip, maybe a tiny
  smiling face) with a "hungry katy" wordmark. Show me 2-3 options. Deliver SVG + PNG sizes
  (favicon, apple-touch-icon, social preview).
- Homepage focuses on recipes: friendly hero with logo, category stickers, newest recipes grid.
- Mobile-first, accessible (contrast, alt text, keyboard support, prefers-reduced-motion).

## Mini-games (in the spirit of cooking mini-game classics, but all original)
Each recipe gets an optional 3-stage game driven by its `game` config:
1. Shop: drag the recipe's real ingredients from a market shelf into a basket; a few silly
   decoy items.
2. Prep: quick tap/swipe challenges matching real steps: chop along dotted lines, pour to a
   measuring line, knead, crack eggs, roll, pleat dumplings, etc.
3. Cook: timing/steadiness challenges: stir in circles, keep heat in the "just right" zone,
   flip at the right moment, plate the dish.
- End with a star rating + "dish complete" sticker. Include an original kitchen-helper mascot.
- Build a reusable library of ~10 mechanics so a recipe's game is just a short config list,
  e.g. game: [knead, roll, cut, boil].
- Runs fully client-side (no backend), touch + mouse, loads only when "Play" is tapped,
  always has a "Skip to recipe" option. The recipe itself stays primary for readers and SEO.
